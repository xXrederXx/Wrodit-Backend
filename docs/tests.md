# Tests

## Backend

Die Backend tests werden automatisiert durchgeführt. Einen manuellen test durchlauf kann man mit `gradlew test` starten.

## Frontend

Das Frontend besitzt keine automatisierten test. Es wird jedoch durch protokolierte User Acceptance tests getestet.

Beim testen wird das [Template](./tests/UAT_Template.md) benutzt und als UAT_Datum.md geschpeichert.
