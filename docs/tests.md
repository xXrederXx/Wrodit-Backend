# Tests

## Backend

Die Backend-Tests werden automatisiert durchgeführt. Einen manuellen Testdurchlauf kann man mit `gradlew test` starten.

## Frontend

Das Frontend besitzt keine automatisierten Tests. Es wird jedoch durch protokollierte User-Acceptance-Tests geprüft.

Beim Testen wird das [Template](./tests/UAT_Template.md) benutzt und als UAT_Datum.md gespeichert.
